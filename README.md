## Quick Start

### Prerequisites
- Java JDK 21 (for modern versions) or JDK 8 (for 1.12.2 and older)
- IntelliJ IDEA (recommended) or Eclipse
- Internet connection (Gradle will download dependencies)

### Open in IntelliJ IDEA
1. Open IntelliJ IDEA
2. File → Open → Select this folder
3. Wait for Gradle sync to complete
4. Run the `runClient` Gradle task to test

### Open in Eclipse
1. Open a terminal in this folder
2. Run: `./gradlew eclipse` (or `gradlew.bat eclipse` on Windows)
3. Import as Existing Project in Eclipse

### Build the Mod
```bash
./gradlew build
```
The compiled .jar will be in `build/libs/`
